# Study notes (seed)

## Primary seed (10 steps)

Source: https://x.com/DataChaz/status/2101206777924858319  
Quoted roadmap article: [@0xCodila](https://x.com/0xCodila/status/2100984487802708306) / https://x.com/i/article/2077744776565149697

Teachable steps (Ormus framing — primitives over multipliers):

1. LLMs create. Agents act. Jev decides the next move.
2. Turn agent forks into Choice, Score, and Noul (typed answers; confidence from the model).
3. Build with OpenAI, Anthropic, or xAI first; swap Jev in without rebuilding the graph.
4. Start with shared state, parallel decisions, risk thresholds, and an execution queue.
5. Batch decisions instead of making them sequentially.
6. Put Jev at bounded forks: agent, model, tool, browser action, or human escalation.
7. Benchmark the whole loop, not just individual model calls.
8. Rank wide, read narrow: shortlist first, then spend compute on what matters.
9. Reuse State → Questions → Action → Verify.
10. Keep Jev out of math, writing, and irreversible execution.

Suite repos map 1:1 to these patterns — see hub README suite map.

Third-party posts may cite speed/cost multipliers from TypeSafe tests. Ormus does not restate those as product claims; attribute or omit.
